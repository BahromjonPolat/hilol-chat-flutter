### 1. `Map<String, String>` type error (register)
**Muammo:** `FcrmChat.register` ichida `userData['registered'] = true` qilganda `type 'bool' is not a subtype of type 'String'` xatosi.
**Sabab:** Dart `userData` ni `Map<String, String>` deb inference qilgan (barcha value'lar string edi).
**Yechim:** `hilol_chat_register_bloc.dart` da `final Map<String, dynamic> userData = {...}` deb aniq type ko'rsatildi.

## UI tuzatmalar

### 4. PopupMenuButton splash rangi
**Muammo:** Long press va tap da splash effekti ko'rinardi.
**Yechim:** `PopupMenuButton`-ni `Theme(data: Theme.of(context).copyWith(splashColor: transparent, highlightColor: transparent, hoverColor: transparent))` bilan o'raldi.

### 5. Row `mainAxisAlignment.end` ishlamadi
**Muammo:** Bubble ichidagi vaqt/status Row `end` da turmadi.
**Sabab:** `Column(crossAxisAlignment: CrossAxisAlignment.start)` loose constraints beradi — Row o'z kengligini bilmaydi.
**Yechim:** `IntrinsicWidth` + `CrossAxisAlignment.stretch` kombinatsiyasi:
- `IntrinsicWidth` — Column-ni eng keng child kengligi bilan cheklaydi
- `CrossAxisAlignment.stretch` — barcha childlar (Row ham) to'liq kenglikni oladi
- `mainAxisAlignment: MainAxisAlignment.end` endi ishlaydi

### 6. Duplicate xabar muammosi (yangi user birinchi xabar)
**Muammo:** Ro'yxatdan o'tmagan user xabar yuborganda: register → send → birinchi xabar duplicate bo'lardi.
**Sabab:** `register` handler muvaffaqiyatdan so'ng har doim `getMessages()` chaqirardi. `onSuccess` orqali `sendMessage` ham qo'shilganda event queue: `[sendMessage, getMessages]`. Agar `sendMessage` API tezroq tugasa — server xabari `getMessages` natijasida qaytadi va optimistic xabar bilan duplikat hosil bo'ladi.
**Yechim:** `register` handlerda `getMessages()` faqat `onSuccess == null` bo'lganda chaqirilsin:
```dart
onSuccess?.call();
if (onSuccess == null) {
  add(const HilolChatEvent.getMessages());
}
```
