## Tuzatilgan xatolar

### 1. `Map<String, String>` type error (register)
**Muammo:** `FcrmChat.register` ichida `userData['registered'] = true` qilganda `type 'bool' is not a subtype of type 'String'` xatosi.
**Sabab:** Dart `userData` ni `Map<String, String>` deb inference qilgan (barcha value'lar string edi).
**Yechim:** `hilol_chat_register_bloc.dart` da `final Map<String, dynamic> userData = {...}` deb aniq type ko'rsatildi.

## Yangi feature'lar

### 2. Chat sahifasida registration flow
**Talablar:**
- Chat ochilganda registered bo'lsa → xabarlar yuklansin
- Registered bo'lmasa → chat sahifasi bo'sh ko'rinsin
- Send bosganda:
  - `defaultUserData` bor → avtomatik register + xabar yuborsin
  - `defaultUserData` yo'q → RegisterPage ga push qilsin
- RegisterPage dan keyin → HilolChatBloc yangilansin, xabarlar yuklansin

**O'zgargan fayllar:**
- `hilol_chat_state.dart` — `HilolChatRegisterModel? defaultUserData` field qo'shildi
- `hilol_chat_event.dart` — `setupUserData`, `onRegistered` eventlar qo'shildi
- `hilol_chat_bloc.dart` — `initialize`-da `defaultUserData` saqlanadi; `register` muvaffaqiyatdan keyin `getMessages` chaqiriladi; `onRegistered` handleri qo'shildi
- `hilol_chat_page.dart` — `initState`-dan register page-ga redirect olib tashlandi
- `hilol_chat_input.dart` — Send button registration holati tekshiradi
- `hilol_chat_register_page.dart` — `onSuccess`-da `HilolChatBloc.onRegistered` + `context.pop()`

### 3. Message edit (update) feature
**Talablar:** Edit bosganda xabar matni TextField ga tushsin, Send bosganda yangi xabar sifatida emas, mavjud xabar yangilansin.

**O'zgargan fayllar:**
- `chat_repository.dart` — `editMessage({messageId, content})` abstract method qo'shildi
- `chat_repository_impl.dart` — SDK `_chat!.editMessage()` orqali implement qilindi
- `hilol_chat_event.dart` — `startEditing`, `cancelEditing`, `editMessage` eventlar qo'shildi
- `hilol_chat_state.dart` — `ChatMessage? editingMessage` field qo'shildi
- `hilol_chat_bloc.dart` — yangi handlerlar: `startEditing`, `cancelEditing`, `editMessage` (local state yangilaydi)
- `hilol_chat_bubble.dart` — Edit popup `startEditing` event yuboradi
- `hilol_chat_input.dart`:
  - `BlocConsumer` bilan `editingMessage` o'zgarishini kuzatadi
  - `editingMessage != null` bo'lsa editing indicator banner ko'rinadi (primary color chiziq, xabar preview, ✕ cancel)
  - Send bosganda `editMessage` event yuboriladi
  - Fayl picker editing paytida yashiriladi

## UI tuzatmalar

### 4. PopupMenuButton splash rangi
**Muammo:** Long press va tap da splash effekti ko'rinardi.
**Yechim:** `PopupMenuButton`-ni `Theme(data: Theme.of(context).copyWith(splashColor: transparent, highlightColor: transparent, hoverColor: transparent))` bilan o'raldi.

### 5. Row `mainAxisAlignment.end` ishlamadi
**Muammo:** Bubble ichidagi vaqt/status Row `end` da turmadi.
**Sabab:** `Column(crossAxisAlignment: CrossAxisAlignment.start)` loose constraints beradi — Row o'z kengligini bilmaydi.
**Yechim:** `IntrinsicWidth` + `CrossAxisAlignment.stretch` kombinatsiyasi:
- `IntrinsicWidth` — Column-ni eng keng child kengligi bilan cheklaydi
- `CrossAxisAlignment.stretch` — barcha childlar (Row ham) to'liq kenglikni oladi
- `mainAxisAlignment: MainAxisAlignment.end` endi ishlaydi
