## Yangi feature'lar

### 1. In-app notification banner

**Talab:**
- Yangi xabar kelganda yuqoridan notification chiqsin
- User chat sahifada bo'lsa notification chiqmasin
- Navigation-agnostic: Navigator 1.0 va go_router bilan ham ishlaydi
- Notification bosilganda chat sahifasiga o'tish uchun callback

**Arxitektura yondashuvi:**
- `HilolChatConfig` da `GlobalKey<NavigatorState>? navigatorKey` va `void Function()? onNotificationTap` qo'shildi
- `HilolChatState` da `bool isChatPageVisible` field qo'shildi
- `HilolChatEvent.setChatVisible(bool visible)` event qo'shildi
- `HilolChatBloc` da `_navigatorKey`, `_onNotificationTap`, `_notificationEntry` instance fields

**Ishlash tartibi:**
1. `initialize` handlerda `_navigatorKey` va `_onNotificationTap` config'dan saqlanadi
2. `HilolChatPage.initState` → `setChatVisible(true)` dispatch qiladi
3. `HilolChatPage.dispose` → `setChatVisible(false)` dispatch qiladi
4. `addMessage` handleri: non-user xabar kelsa va `!state.isChatPageVisible` → `_showNotification(message)` chaqiriladi
5. `setChatVisible(true)` → `_dismissNotification()` chaqiriladi (user sahifaga kirsa notification yashiriladi)

**O'zgargan fayllar:**
- `hilol_chat_config.dart` — `navigatorKey`, `onNotificationTap` qo'shildi (avvalgi sessionda)
- `hilol_chat_state.dart` — `isChatPageVisible` field qo'shildi (avvalgi sessionda)
- `hilol_chat_event.dart` — `setChatVisible(bool visible)` event qo'shildi (avvalgi sessionda)
- `hilol_chat_bloc.dart`:
  - `_navigatorKey`, `_onNotificationTap`, `_notificationEntry` instance fields
  - `initialize` handlerda config'dan saqlanadi
  - `addMessage` da notification triggeri
  - `setChatVisible` handler (isChatPageVisible + dismiss)
  - `_showNotification()` metodi: OverlayEntry yaratib navigator overlay'ga qo'shadi
  - `_dismissNotification()` metodi
  - `close()` da `_dismissNotification()` chaqiriladi
- `hilol_chat_page.dart`:
  - `_bloc` reference saqlanadi `initState`'da
  - `initState` → `setChatVisible(true)`
  - `dispose` → `setChatVisible(false)`
- `hilol_chat_notification_banner.dart` (yangi):
  - `StatefulWidget` + `SingleTickerProviderStateMixin`
  - Yuqoridan pastga `SlideTransition` animatsiyasi (300ms easeOut)
  - 4 soniyadan keyin avtomatik yashirinadi
  - Overlay'da `Positioned(top:0, left:0, right:0)` — xavfsiz joylashuv
  - Sender nomi + xabar preview (rasm bo'lsa "📷 Photo")
  - Tap → `onTap` callback + dismiss

**Texnik nuanslar:**
- `OverlayEntry` late binding: `dismiss()` closure `entry` referensini capture qiladi, `_notificationEntry == entry` tekshiruvi bilan noto'g'ri dismiss'ni oldini oladi
- `senderName` SDK da `String?` — `?? ''` ishlatildi
- `isImage` extension import shart emas — `metadata?['is_image'] == true` to'g'ridan tekshirildi
- `flutter/widgets.dart` import OverlayEntry, GlobalKey, NavigatorState uchun

## Arxitektura

```
HilolChatBloc
  ├── state.isRegistered       — registration holati
  ├── state.defaultUserData    — avtomatik register uchun ma'lumotlar
  ├── state.editingMessage     — hozir tahrirlanayotgan xabar
  └── state.isChatPageVisible  — chat sahifasi ochiqmi

Instance fields:
  ├── _navigatorKey            — overlay insertion uchun
  ├── _onNotificationTap       — host app routing callback
  └── _notificationEntry       — joriy overlay entry

Events:
  initialize → setupUserData → register → onRegistered
  startEditing → editMessage / cancelEditing
  sendMessage → sendImage → addMessage (→ _showNotification)
  getMessages
  setChatVisible(true/false)
```
